# thirdbase — Design System

A brand & presentation design system for **thirdbase**, a full-funnel marketing agency.

> _"We are thirdbase: a full-funnel marketing agency."_

thirdbase sells **a three-way approach to sales**:

1. **01 · Digital Marketing** — paid social & paid search

**720 × 405 pt** (10 × 5.625 in, 16:9). All tokens are that geometry scaled to a
**1280 × 720 px** stage — the factor is exactly `1280/720 = 1.7778` (pt → px).

> **Do not round these values to a 4/8-px grid.** The margin really is `25.2px` and
> the card inset really is `12.8px`. Use the tokens in `tokens/slides.css`.

## Content fundamentals

**Voice.** Confident, plain-spoken, consultative — an agency talking to a prospective
client. Sentences are short and declarative. It leads with a claim, then backs it with
data: _"Sessions remain steady, but the organic rankings have dropped slightly compared
to last year."_

**Person.** Uses **"we"** for the agency and **"you/your"** for the client
(_"We want to bring that number down."_). Collective, partnership-oriented.

**Casing.** Sentence case for body and most headings. Section eyebrows and small labels
are **UPPERCASE with wide tracking** ("THE PROBLEM", "ORGANIC SEARCH"). The wordmark
**"thirdbase" is always lowercase**. Numbers are always **zero-padded to two digits**
(`01`, `02`, `03`) — this is a signature.

**Numbers & proof.** Heavy use of single hero metrics ("73%", "+1%", "−12%") with a
one-line explanation and a cited source ("Source: study by BluePaperclip"). Prices shown
in DKK ("6.000 DKK") — the agency is Danish/European; use the period thousands separator.

**Emoji / exclamation.** None. No emoji, no exclamation marks, no hype words. The tone is
measured and evidence-led.

**Examples of on-brand copy:**
- Eyebrow: `A LOOK AT WHAT WE DO`
- Title: `A three-way approach to sales`
- Stat: `73% of companies are underutilizing their customer data…`
- Section: `The Problem` · `Paid Social` · `Organic Search` · `CRM System`

## Visual foundations

**Palette.** Deliberately tight — one hero accent, one secondary, a neutral ramp.
The deck's own palette slide names six colors:
- **Primary Color `#FF442B`** — the signature. Card/tile fills, numbers, hero stats, checks, the mark.
- **Primary Accent `#3355FF`** — secondary highlight.
- **Primary Font Color `#444444`** — all body **and title** text. Titles are *not* black.
- **Secondary Font Color `#9E9E9E`** — captions, sources, image/chart placeholders.
- **Background Color `#FFFFFF`** · **Background accent `#F3F3F3`** — panel fills.
- **Secondary Background Color `#242424`** — dark surfaces.
- Plus **`#F5F5F5`** for text on colored/dark fills and **`#292B3D`** for table ink.

**Type.** **Inter Tight** everywhere — one family, no pairing. The deck embeds only
**Regular (400)** and **Bold (700)** (+ italics) — there is **no 500 or 600 weight in the
brand**. Large titles are Regular; card titles and subheadings are Bold. Tracking is 0.

**Backgrounds.** Flat color fills — **no gradients, no textures, no patterns**. White is
the default; `#F3F3F3` fills panels; `#242424` for dark surfaces.

**The diamond motif.** The mark is four rotated squares (a diamond cluster) in `#FF442B`.

**Corner radii.** **Zero.** Every shape in the source deck is `prstGeom="rect"` — cards,
tiles, swatches, and image wells are all perfectly square. Use `--slide-radius` (0) on
slide surfaces. The `--radius-*` tokens exist only for web/app surfaces.

**Borders.** Hairline **1.3px** rules (the deck's connector weight, `--slide-rule-width`)
for dividers and table rows. Red cards have **no** border.

**Shadows.** **None in the source deck.** Tiles are flat solid fills. The `--shadow-*`
tokens are for web surfaces only.

**Cards.** Solid `#FF442B`, square, 12.8px inset, no border, no shadow. A number sits
top-left at 11pt, the title below it at 21pt bold. Content is top-anchored.

**Transparency / blur.** Essentially none. Colors are solid throughout.

**Motion.** The source is a static deck — no motion is defined. For interactive work keep
it understated: standard ease `cubic-bezier(0.22,0.61,0.36,1)`, ~120–200ms, fades and
short slides. No bounce. **Flagged: motion is an addition, not from the source.**

**Hover / press.** Not defined in the source. Recommended: hover darkens the fill
(`--tb-red-600`, `--tb-blue-600`); ghost/outline fills with `--tb-bg-accent`. Focus = soft
red ring (`--focus-ring`). **Flagged as an addition.**

**Layout.** Tight, generous-width margins: **25.2px** on all four edges (~2% of stage
width) — the deck uses nearly the full canvas. Content is left-aligned and grid-driven;
3-up grids echo the "three-way" theme. Fixed elements: logo bottom-left, title top-left.

**Imagery vibe.** The source uses `#9E9E9E` gray blocks as placeholders for photos, charts,
and avatars — photography is deliberately deferred. One stock photo appears in the
campaigns slide (kept as `assets/placeholder-photo.png`; **it carries an Unsplash+
watermark and must be replaced before any real use**).

## Iconography

The source contains **no custom icon set** and no icon font. The only bespoke glyph is the
**diamond mark** (`assets/mark-thirdbase.png`). Emoji are **not** used. A checkmark `✓` and
an en-dash `–` appear as table affordances in the audit comparison — these are plain
Unicode characters, colored red / muted respectively, not icons from a library.

**Guidance for new work:** keep iconography minimal. If icons are genuinely needed, use a
thin geometric line set — **Lucide** (CDN: `https://unpkg.com/lucide-static`) is the closest
match to the geometric, low-contrast feel and is the recommended substitute. **Flag any
icon use to the user**, since the brand did not define an icon system. Prefer the numbering
motif (`01/02/03`) and the diamond over decorative icons wherever possible.

## Fonts

**Inter Tight** is the genuine brand font — the source PPTX embeds it (Regular, Bold,
Italic, Bold Italic) and it is available on Google Fonts, so this is **not a substitution**.
It loads via `@import` in `tokens/fonts.css`.

The PPTX's embedded font binaries are Google's obfuscated `.fntdata` format, not usable
`.ttf`/`.woff2` files, so they could not be self-hosted. **If you need offline/self-hosted
fonts, send the real `.woff2` files** and I'll swap the `@import` for local `@font-face`
rules.

## Components

Reusable React primitives in `components/core/` (namespace exposed as
`window.<Namespace>` — run `check_design_system` for the exact name):

- **Button** — primary / secondary / dark / outline / ghost; sm·md·lg.
- **Tag** — uppercase pill label; neutral / red / blue × soft / solid / outline.
- **NumberBadge** — the `01/02/03` numbering motif.
- **Card** — flat surface, hairline border, optional 3px red top rule / elevation.
- **StatCallout** — oversized hero metric + label + optional delta chip ("73%", "+1%").
- **ComparisonTable** — multi-column spec/feature table (the SEO audit slide).

### Intentional additions
The source is a brand & deck guide with **no explicit component inventory**, so these
primitives were authored to match what the deck actually uses. Each maps directly to a
motif in the PDF (numbering, big stat, audit table, tags, cards) rather than inventing a
generic UI library. Adjust freely — they are a starting vocabulary, not a locked spec.
